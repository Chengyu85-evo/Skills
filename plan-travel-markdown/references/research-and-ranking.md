# 研究与分类口径

## 小红书收藏分类

### 必去候选

- 与用户兴趣高度匹配且具有不可替代性。
- 收藏中多次出现或评价强烈。
- 能自然放入初步路线。
- 时间和预算成本合理。

### 推荐

- 体验质量高且顺路，但不是旅行成立的必要条件。
- 可与附近 must-go 组合。

### 可选

- 有吸引力，但与其他地点重复、天气敏感或需要额外跨区。
- 用作剩余容量、雨天或临时替补。

### 不建议

- 已闭店、长期关闭、明显不适合季节或行程。
- 与更优地点高度重复。
- 交通成本过高，破坏固定交通或主要体验。
- 主要依据为营销内容且缺少有效体验信息。

每个结论保留原笔记链接。不要因为用户收藏就直接宣布为最终 must-go。

## 餐厅分类补充

- 识别早餐、brunch、午餐、下午补给、晚餐或酒吧。
- 检查与当日路线的步行距离、营业时段和预约难度。
- 避免连续多顿同类重餐。
- 区分值得专程前往和仅在顺路时选择。

## 酒店统一比较口径

同时记录：

- 入住日期、人数、房间数、床型与房型。
- 最终含税总价、城市税、早餐、预付和取消截止。
- 房间面积、外窗、空调、电梯与行李寄存。
- 到主要车站和每天首个景点的真实动线。
- 换酒店日是否需要绕路。
- 官方网站与主要 OTA 的核价日期。

每个 option 必须写推荐理由和 concern。不要混排不可取消价与可取消价，不要用旧价格填补当前查询失败。

## 默认停留时长

| 类型 | 默认时长 |
|---|---:|
| 外观拍照点 | 15—30分钟 |
| 公园途经 | 30—60分钟 |
| 公园 + 休息 / 日落 | 1.5—3小时 |
| 教堂普通参观 | 60—90分钟 |
| 单一重点博物馆 | 1.5—2小时 |
| 大型博物馆精选 | 2—2.5小时 |
| 城堡 / 大型历史景点 | 2—2.5小时 |
| 市场午餐 | 60分钟 |
| 街区散步购物 | 1.5—2小时 |
| 正式晚餐 | 1.5小时 |
| 酒吧品鉴 | 60—90分钟 |

所有超过 1 小时的停留都要复核内容量、排队、休息和下一个固定时间。

## 动态事实来源

优先级：景点/交通/酒店/餐厅官方网站 → 政府或目的地官方 → 可靠票务平台。小红书只提供偏好和体验线索，不作为开放时间、价格或安全判断的唯一来源。
